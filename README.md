# 🚀 2026 Vibe Coding 期末專案：[時間管理 5 大迷思]
## 🌟 1. 專題願景 (Vibe)
* **目標對象**：大學生
* **設計風格**：「冷靜理性與知性美」。採用溫暖的米色 (#F9F7F2) 作為基底，搭配低飽和的靜謐藍，營造出如同閱讀質感雜誌般的無壓力氛圍，讓使用者能靜下心思考。
* **核心功能**：深度內容解析： 透過 5 大常見迷思的互動卡片，解析背後心理陷阱。
           多開摺疊交互： 讓使用者能同時對照不同迷思，自由決定閱讀深度。
           狀態診斷測驗： 快速檢測使用者的時間焦慮指數，並給予個性化的行動建議。
  
## 🤖 2. Gemini 協作紀錄 (Prompt Log)
*請貼出你餵給 Gemini 最關鍵的一個 Prompt：*
>你現在是一位專業的前端工程師與 UI／UX 設計師，熟悉 HTML、CSS，並擅長將抽象概念轉化為清楚、易閱讀的網頁版面。
我想製作一個介紹「時間管理 5 大迷思」的主題式網頁，內容以學生族群為主要對象，透過條列與說明方式，幫助使用者理解常見的錯誤時間管理觀念，並提供正確的思考方向。
網頁需以資訊整理與閱讀體驗為核心，不需要複雜功能，重點在於內容結構清楚、視覺舒適。整體風格希望呈現簡約、理性且溫和的感覺，避免過度花俏。
配色以中性色系為主，例如米色、淺灰或淡藍色，搭配圓角卡片式設計，讓每一個迷思都能清楚區分。
字體以易讀為優先，版面留白充足，營造冷靜思考與整理資訊的氛圍。

*在開發過程中，你遇到了什麼 Bug？Gemini 怎麼幫你修好的？*
* **遇到的問題**：當我要求標題「全置中」時，右側的展開按鈕（+ 號）會佔據空間，導致標題文字偏左，無法達成完美的視覺平衡。
* **Gemini 的建議：** Gemini 建議將按鈕從標準的 Flex 排版改為 position: absolute（絕對定位），將其懸浮於右側邊緣。這樣標題文字就能在父容器中自由置中，不再受按鈕位置的推擠。

## 📈 4. 自我心得與反思
* **使用 Vibe Coding (與 AI 對話寫 Code) 的心得：**
這次專題我第一次嘗試用 Vibe Coding 的方式來做網頁，也就是透過和 AI 對話，一步一步把網站做出來。
跟以前自己查資料、拼程式碼相比，這種方式比較不容易卡關，因為只要我把想法講清楚，AI 就能幫我轉成可以實作的程式碼。
在過程中，我發現「怎麼問」其實很重要。當我把想做的功能、風格，甚至是我卡住的地方說清楚，產出的結果就會比較符合我的期待。這也讓我開始思考網站的整體架構，而不只是照著範例做。
